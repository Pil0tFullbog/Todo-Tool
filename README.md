# ✨ Todo App

Eine moderne, minimalistische Todo-App mit einem ansprechenden **dunklen Glow-Design**, entwickelt für den täglichen Einsatz im Browser.

---

## 🚀 Funktionen

* **Hinzufügen:** Erstelle schnell neue Aufgaben.
* **Erledigen:** Hake erledigte Aufgaben mit einem Klick ab.
* **Persistenz:** Lokale Speicherung direkt im Browser (`localStorage`), damit deine Daten erhalten bleiben.
* **Wiederherstellung:** Aufgaben werden beim erneuten Öffnen automatisch wieder geladen.
* **Responsive Design:** Optimierte Darstellung für Desktop-Monitore und Smartphones.

---

## 📂 Projektstruktur

Das Projekt ist übersichtlich in folgende Dateien aufgeteilt:

* `index.html` – Die grundlegende Seitenstruktur und Benutzeroberfläche.
* `design.css` – Styling, futuristische Glow-Effekte und responsive Layout-Regeln.
* `script.js` – Interaktive Todo-Logik und Anbindung an den Local Storage.
* `logo.png` – Website-Icon / Favicon für das Projekt.

---

## 🛠️ Schnellstart

1. Klonen oder herunterladen des Repositories.
2. Doppelklicke auf die Datei `index.html`, um sie direkt in deinem Standard-Browser zu öffnen.

> **Hinweis:** Es ist kein Backend oder Server erforderlich. Die Aufgaben werden ausschließlich lokal auf deinem Gerät gespeichert.
