# Todo

Eine kleine Todo-App mit dunklem Glow-Design.

## Funktionen

- Todos hinzufügen
- Todos abhaken
- Todos lokal im Browser speichern
- Aufgaben nach dem erneuten öffnen wieder anzeigen
- Responsive Darstellung für Desktop und Smartphone

## Dateien

- `index.html` - Seitenstruktur
- `design.css` - Design, Glow-Effekte und responsive Layout-Regeln
- `script.js` - Todo-Logik und lokale Speicherung
- `logo.png` - Website-Icon

## Starten

`index.html` direkt im Browser öffnen.

Die Aufgaben werden nur lokal im verwendeten Browser gespeichert. Es wird kein Server benötigt.
